# warcryer.github.io

The project page for [Warcryer](https://warcryer.github.io/): push-to-talk voice for large gaming alliances, where the event roster decides who hears whom.

A plain static site: `index.html`, `style.css`, the emblem, fonts and screenshots. Whatever is on `main` is published by GitHub Pages.

The screenshots come from the walkthrough recording, which uses invented clans and players. Fonts are Cinzel and Inter, both under the SIL Open Font License. Everything else here is MIT licensed, like the client.

Warcryer is a community project. It is not affiliated with or endorsed by NCSOFT or any game publisher.
